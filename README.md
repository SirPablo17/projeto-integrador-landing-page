# Projeto Integrador — Jailson | Manutenção de Hardware

## 1. Sobre o Projeto

O projeto consiste no desenvolvimento de uma landing page para divulgação de serviços de manutenção de computadores e equipamentos eletrônicos, com foco no atendimento ao público de Teresina, Piauí.

A aplicação foi desenvolvida para apresentar os serviços oferecidos pelo profissional, fornecer informações sobre o processo de atendimento e facilitar o contato entre clientes e prestador de serviços.

O site possui uma interface moderna, intuitiva e responsiva, buscando proporcionar uma experiência simples e acessível aos usuários.

## 2. Objetivo

Desenvolver uma solução web que permita divulgar serviços de manutenção de hardware, apresentar informações relevantes aos clientes e facilitar a solicitação de orçamentos por meio do WhatsApp.

## 3. Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5:** estruturação e organização dos conteúdos da página.
- **CSS3:** estilização, identidade visual, organização dos elementos e responsividade.
- **JavaScript:** implementação de interações, validação de formulários e integração com o WhatsApp.

## 4. Funcionalidades Implementadas

A aplicação apresenta as seguintes funcionalidades:

- Apresentação dos serviços de manutenção de computadores.
- Seção sobre o profissional.
- Apresentação das etapas do atendimento.
- Seção de análise de problemas comuns em computadores.
- Formulário para solicitação de orçamento.
- Validação dos campos obrigatórios.
- Verificação do preenchimento da descrição do problema.
- Geração automática de mensagem com os dados do cliente.
- Integração com o WhatsApp para encaminhamento da solicitação.
- Navegação entre as seções da página.
- Layout responsivo para diferentes tamanhos de tela.

## 6. Como Executar o Projeto

Para visualizar a aplicação:

1. Faça o download ou clone do repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador, como Google Chrome ou Microsoft Edge.

Não é necessário instalar dependências adicionais para executar a versão atual da aplicação.

## 7. Testes Realizados

Foram realizados testes para verificar o funcionamento e a usabilidade da aplicação.

Entre os testes realizados estão:

- Navegação entre as seções da página.
- Funcionamento dos links e botões.
- Preenchimento e validação do formulário.
- Verificação de campos obrigatórios.
- Verificação do limite mínimo de caracteres na descrição.
- Geração da mensagem para o WhatsApp.
- Testes de visualização em diferentes tamanhos de tela.

Os testes de navegação apresentaram resultado satisfatório, com 6 de 6 verificações realizadas com sucesso.

Os testes de responsividade foram realizados em resoluções de celular e tablet, apresentando adaptação adequada dos elementos da interface.

## 8. Considerações Finais

O desenvolvimento deste projeto permitiu aplicar conhecimentos de desenvolvimento web, utilizando HTML5, CSS3 e JavaScript na construção de uma solução funcional.

A aplicação busca facilitar a divulgação dos serviços de manutenção de computadores e proporcionar um canal de comunicação mais acessível entre o profissional e seus clientes.

O projeto também possibilitou colocar em prática conceitos de organização de código, responsividade, validação de dados e experiência do usuário (UI/UX).
